# 免费发布方案

Render Blueprint 需要绑定付费信息时，可以先走免费路线。核心取舍是：免费静态托管可以让任何平板打开网页，但没有真正的云端数据库；微信小程序可以在微信里运行，但正式发布和多设备同步仍需要账号、审核和后端。

## 方案 A：GitHub Pages 免费网页版

适合：先做试点、演示、单台或少量平板采集。

本项目已经支持纯静态模式：如果 `/api` 后端不可用，App 会自动把测评记录保存到当前平板浏览器的 `localStorage`，AI 评分走本地演示评分。

操作：

1. 把当前代码推到 GitHub。
2. 打开仓库 `Settings`。
3. 进入 `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选 `main`，目录选 `/(root)`。
6. 保存后等待 GitHub Pages 发布。

发布后地址一般是：

```text
https://trchen12.github.io/cognition-hearing-game/
```

限制：

- 数据只保存在当前平板浏览器里，不会自动汇总到中央后台。
- 更换浏览器、清理缓存或换设备后，看不到其他设备数据。
- 真实 AI 评分、集中数据库、管理员账号这些仍需要后端服务。

## 方案 B：Cloudflare Pages 免费网页版

适合：想要更稳定的全球静态访问和自动部署。

操作：

1. 登录 Cloudflare。
2. `Workers & Pages` → `Create application` → `Pages` → `Connect to Git`。
3. 选择 GitHub 仓库。
4. 构建命令留空。
5. 输出目录填 `/` 或留空按根目录部署。
6. 部署后会得到 `*.pages.dev` 公网地址。

限制与 GitHub Pages 一样：没有后端时只能做本机保存。

## 方案 C：微信小程序

我已经在项目里新增了：

```text
wechat-miniprogram/
```

这个版本可以导入微信开发者工具运行，默认不需要付费服务器：

- 本机微信缓存保存测评记录。
- 任务卡、选择题、连线、立方体、钟表画布、句子转写、流畅性计时、延迟回忆、定向题都已包含。
- 点击下一题自动提交并评分。
- 后台页可查看本机记录并复制 JSON。

导入步骤：

1. 安装微信开发者工具。
2. 选择 `导入项目`。
3. 项目目录选择 `cognition-hearing-game/wechat-miniprogram`。
4. 没有 AppID 时可以先用测试号或游客模式预览。

正式多平板同步：

- 需要微信小程序 AppID。
- 如接入 HTTPS 后端，需要在微信公众平台配置合法服务器域名。
- 如接入云开发或云数据库，需按腾讯/微信当时的计费策略评估免费额度和用量。

## 建议路线

先用 GitHub Pages 发布免费网页版，最快拿到一个所有平板可打开的公网链接；同时用微信开发者工具预览小程序版。等流程稳定后，再决定是接云数据库，还是走正式微信小程序发布。
