# Git Force Push 事故复盘

> 来源：[[git-force-push-lessons]]（naoli-town 仓库 docs/）

## 三次事故

### 事故 1：用 `git init` 而不是 `git clone`
- **原因**：在新电脑上 `git init` 创建了独立仓库，而不是 `git clone` 拉取已有仓库
- **后果**：本地和远程历史完全不同，被迫 force push 覆盖了远程 `character-guide` 分支
- **教训**：**永远用 `git clone`，不要 `git init`**

### 事故 2：基于旧 main 建分支
- **原因**：本地 main 没 pull 就建了新分支，结果基于旧版本
- **后果**：新分支和远程 main 没有共同祖先，无法 merge
- **教训**：**建分支前先 `git checkout main && git pull`**

### 事故 3：裸用 `git push --force`
- **原因**：两次都用了 `--force` 而不是 `--force-with-lease`
- **后果**：直接覆盖远程，别人 commit 会丢失
- **教训**：**用 `--force-with-lease`，或者先 pull 再 push**

## 正确流程

```
新电脑：git clone → git checkout 分支
日常：  git pull → 改代码 → git add . → git commit → git push
建分支：git checkout main && git pull → git checkout -b 新分支
push被拒：git pull --rebase → git push（不要 force！）
```
