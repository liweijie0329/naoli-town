# MoCA Quest 微信小程序原型

这是 `cognition-hearing-game` 的微信小程序版本，适合先在微信开发者工具和真实平板上预览。

## 导入

1. 打开微信开发者工具。
2. 选择 `导入项目`。
3. 项目目录选择本文件夹：`wechat-miniprogram`。
4. 没有正式 AppID 时，可先用测试号或游客模式运行。

## 当前能力

- 参加者姓名、年龄、性别、教育水平登录。
- 横屏平板单页作答，任务页不需要上下滑动。
- 侧边栏默认隐藏，可进入任务、结果、后台、技术细节和返回首页。
- 覆盖附件 MoCA 的 15 张任务卡；命名、连续减 7、句子复述、抽象和定向题均逐题分页。
- 交替连线、复制立方体、画钟表提供画布区域；连线圆圈默认只能点击一次。
- 数字顺背/倒背、警觉性、句子复述、流畅性、抽象、延迟回忆和定向题预留系统扬声器/麦克风工作流。
- 点击下一题时自动提交并评分。
- 后台记录总分、每题得分、总用时、每题用时、行为指标、画图临时图片路径和评分结果。
- 默认使用微信本地缓存保存记录，不需要付费服务器。
- 后台页支持复制 JSON，便于试点期手工汇总。

## 语音与定位

`app.json` 已配置微信同声传译插件 `WechatSI`、录音权限和定位权限。开发者工具里需要确认已允许插件和权限；真机调试时用户首次使用麦克风/定位会弹出授权。

定向题默认用 `wx.getLocation` 记录经纬度。若要自动反查城市和地点，请在 `utils/config.js` 填入腾讯位置服务 Key，并在微信公众平台把 `https://apis.map.qq.com` 加入 request 合法域名。

## 接入联网后台

编辑：

```text
utils/config.js
```

把 `apiBase` 改成 HTTPS 后端地址，例如：

```js
module.exports = {
  apiBase: "https://example.com"
};
```

后端需要支持：

- `POST /api/ai-score`
- `GET /api/sessions`
- `POST /api/sessions`

正式发布微信小程序时，还需要在微信公众平台配置合法服务器域名。
